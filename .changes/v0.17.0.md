## v0.17.0 - 2026-09-04

### Improvements

- [runtime] Type an instance indexed out of a `count` or `for_each` reference with the same required attributes as a direct reference in a module's generated schema [#609](https://github.com/pulumi/pulumi-hcl/pull/609)

### Bug Fixes

- [converter] Import a resource's values from Terraform state even when its provider declares a schema version, instead of falling back to an id-only import that resource types supporting no import cannot serve [#595](https://github.com/pulumi/pulumi-hcl/pull/595)

- [converter] Record the schema version imported Terraform state was written at, so a provider upgrades that state only when it is behind the schema version the provider serves [#596](https://github.com/pulumi/pulumi-hcl/pull/596)

- [runtime] Fill an omitted resource input from its schema `const` value when the const is an integer [#599](https://github.com/pulumi/pulumi-hcl/pull/599)

- [codegen] Write inputs named after a meta-argument (`count`, `lifecycle`, `source`, ...) in the `_` escaping block [#600](https://github.com/pulumi/pulumi-hcl/pull/600)

- [converter] Read inputs from the `_` escaping block [#600](https://github.com/pulumi/pulumi-hcl/pull/600)

- [converter] Convert top-level `version`, `protect`, `parent`, ... on resource and data blocks to inputs, not options [#602](https://github.com/pulumi/pulumi-hcl/pull/602)

- [codegen] Emit `for_each` on a provider block from a provider resource with a `range` option [#604](https://github.com/pulumi/pulumi-hcl/pull/604)

- [converter] Convert a provider block with `for_each` to a provider resource with a `range` option [#603](https://github.com/pulumi/pulumi-hcl/pull/603)

- [runtime] Fix an intermittent replace of a resource that a `moved` block moves out of a module [#586](https://github.com/pulumi/pulumi-hcl/pull/586)
