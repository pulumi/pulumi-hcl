## v0.19.1 - 2026-11-02

### Bug Fixes

- [codegen] Write the full `replace_on_changes`, `hide_diffs` and `additional_secret_outputs` paths, and write map keys as an index [#760](https://github.com/pulumi/pulumi-hcl/pull/760)

- [converter] Keep map keys unchanged in references and `ignoreChanges` paths [#760](https://github.com/pulumi/pulumi-hcl/pull/760)

- [runtime] Apply the schema `replaceOnChanges` paths to each resource, and resolve `hide_diffs` paths against output properties [#760](https://github.com/pulumi/pulumi-hcl/pull/760)

- [resource-host] Forward `triggers_replace` and the other resource options of resources inside an `hcl_module` [#765](https://github.com/pulumi/pulumi-hcl/pull/765)

- [codegen] Refer to a provider named after its package as `provider = <pkg>` [#710](https://github.com/pulumi/pulumi-hcl/pull/710)

- [converter] Use an un-aliased `provider` block for the resources and invokes of its package [#710](https://github.com/pulumi/pulumi-hcl/pull/710)

- [resource-host] Accept attribute syntax for the list- and set-nested attributes of plugin-framework providers, such as `helm_release.set` [#772](https://github.com/pulumi/pulumi-hcl/pull/772)

- [runtime] Accept `depends_on` on an undeclared module output, and name the kind of object in undeclared reference errors [#777](https://github.com/pulumi/pulumi-hcl/pull/777)

- [runtime] Fix "resource hook already registered" when one HCL component with a precondition, postcondition, or provisioner is instantiated more than once [#780](https://github.com/pulumi/pulumi-hcl/pull/780)

- [converter] Handle a name that starts with a UTF-8 byte order mark [#781](https://github.com/pulumi/pulumi-hcl/pull/781)

- [codegen] Handle a name that starts with a UTF-8 byte order mark [#781](https://github.com/pulumi/pulumi-hcl/pull/781)

- [converter] Convert `one()` of a `MaxItems: 1` field to the flattened field when converting HCL to PCL [#785](https://github.com/pulumi/pulumi-hcl/pull/785)

- [converter] Read a TypeSet `MaxItems: 1` block with `one()` when converting PCL to HCL [#784](https://github.com/pulumi/pulumi-hcl/pull/784)
