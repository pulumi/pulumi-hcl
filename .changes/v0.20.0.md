## v0.20.0 - 2026-11-09

### Improvements

- [codegen] Add the `SkipDefaultCreateBeforeDestroy` option to omit the default `create_before_destroy` from generated HCL [#818](https://github.com/pulumi/pulumi-hcl/pull/818)

### Bug Fixes

- [resource-host] Apply the bridge mappings of Terraform providers in local HCL components, such as `MaxItems: 1` blocks [#795](https://github.com/pulumi/pulumi-hcl/pull/795)

- [runtime] Resolve the block types of a child module with the module's own `required_providers`, not the root module's [#804](https://github.com/pulumi/pulumi-hcl/pull/804)

- [converter] Convert a resource or data source against the provider that its `provider` meta-argument selects [#802](https://github.com/pulumi/pulumi-hcl/pull/802)

- [runtime] Install, type and run a resource or data source with the provider that its `provider` meta-argument selects [#802](https://github.com/pulumi/pulumi-hcl/pull/802)

- [runtime] Reject an extension's type spelled with its base provider's prefix (such as `extbase_greeting` for `myext:index:Greeting`), which no schema declares since extension types moved into their own namespace [#802](https://github.com/pulumi/pulumi-hcl/pull/802)

- [converter] Convert calls to the provider functions of a provider with a renamed local name [#807](https://github.com/pulumi/pulumi-hcl/pull/807)

- [converter] Import the Terraform state of a provider whose name is not the prefix of its resource types [#808](https://github.com/pulumi/pulumi-hcl/pull/808)

- [runtime] Resolve the block types of a provider whose local name is not its package name [#809](https://github.com/pulumi/pulumi-hcl/pull/809)

- [converter] Give unique PCL names to declarations that share a name in HCL [#822](https://github.com/pulumi/pulumi-hcl/pull/822)

- [converter] Convert a provider that a module receives through `configuration_aliases` [#826](https://github.com/pulumi/pulumi-hcl/pull/826)
